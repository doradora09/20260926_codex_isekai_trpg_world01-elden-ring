# ゲーム知識で異世界転生してみた with Codex — 第1世界・エルデンリング編

Codexと対話しながら進行した、TTRPG風の異世界転移物語の公開アーカイブです。
DAY1からDAY98までの本編、挿絵、生徒名鑑、サイドストーリー、旅日誌を収録しています。

## どのように作ったか

人間が行動方針を決め、Codexが進行役・NPC・文章・Web画面・画像生成を担当しました。
判定を使う場面では条件を定めてプログラムでサイコロを振り、結果を物語に反映しています。
物語の進行に合わせて、装備や地図、攻略情報、キャラクターの描写も更新しました。

## 閲覧について

HTML・CSS・JavaScriptと画像で構成された静的サイトです。閲覧にAPIキーやChatGPTの契約は不要です。
このサイト上でAIが新しい話を生成するわけではありません。しおり等は閲覧しているブラウザーに保存します。

本作品はゲームを題材とする非公式の創作・実験記録です。原作の名称・設定の権利は各権利者に帰属します。

## 判定記録の公開形式

各ターンの状態・判定条件・出目など234件は、`records-data.js`の1ファイルにまとめています。
記録画面 `records.html` だけがこのデータを読み込みます。本文の通し読みには読み込みません。

- データはJSONをgzip圧縮し、JavaScriptから読み込めるBase64として格納しています。
- 記録ごとの値は保持し、一覧・種類・ターン検索で選べます。
- 各記録は「この記録をJSONで保存」で個別に取り出せます。
- 閲覧にはgzip展開に対応した現行ブラウザーを利用してください。
- 記録に残る条件ファイルのハッシュは制作時の原本に対する値です。公開版のファイル形式変更とは区別してください。
